# Doska

Интерактивная бесконечная онлайн-доска для визуального мышления, архитектурного проектирования и командного брейншторма.

## Структура монорепозитория (`pnpm` + `Turborepo`)

- `apps/web` (`@doska/web`) — веб-приложение на **Next.js App Router + React + TypeScript + Tailwind CSS + Lucide**:
  - `/` — дашборд досок с мини-превью, поиском, переименованием, созданием пустых и демо-досок, локальным хранением в `IndexedDB`.
  - `/board/[id]` — интерактивный бесконечный холст во весь экран (инструменты, горячие клавиши, контекстная панель стилей, оверлей редактирования текста, `Undo`/`Redo`, зум и интерактивная миникарта).
- `packages/canvas-core` (`@doska/canvas-core`) — движок бесконечного холста:
  - аффинная камера (`screenToWorld`, `worldToScreen`, `zoomAtPoint`, `panCamera`, `fitCameraToBounds`),
  - пространственный R-Tree индекс на базе `rbush` (`viewport culling`, `marquee` выделение, `hitTestPoint` с учётом `rotation` и `zIndexKey`),
  - расчёт 8 ручек масштабирования + вращения и направляющих выравнивания (`smart guides`),
  - High-DPI `Canvas2DRenderer` (адаптивная точечная сетка, стикеры с мягкой тенью и автоподбором шрифта, фигуры, текст),
  - `HistoryManager` (`undo` / `redo` / `pushSnapshot`).
- `packages/shared` (`@doska/shared`) — доменные типы элементов (`StickyNoteElement`, `ShapeElement`, `TextElement`), палитры цветов, генератор лексикографических дробных индексов слоёв (`generateKeyBetween`, `bringToFrontKey`, `sendToBackKey`) и фабрика демо-сцены.
- `docs/obsidian` — продуктовая и архитектурная база знаний проекта.

## Быстрый старт

```bash
pnpm install
pnpm dev
```

Проверка типов, модульные тесты (`Vitest`) и production-сборка:

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Горячие клавиши на холсте

| Клавиша | Действие |
| --- | --- |
| `V` | Курсор (выделение, перемещение, ресайз, вращение) |
| `H` / удержание `Space` | Рука (панорамирование холста) |
| `N` | Создать стикер |
| `R` | Создать прямоугольник |
| `O` | Создать эллипс |
| `D` | Создать ромб |
| `T` | Создать текстовый блок |
| `Двойной клик` | Редактирование текста внутри элемента |
| `Ctrl/Cmd + D` | Дублировать выделенные элементы |
| `Delete` / `Backspace` | Удалить выделенные элементы |
| `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` | Отменить / Повторить |
